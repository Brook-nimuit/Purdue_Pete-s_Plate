# Purdue_Pete-s_Plate
This repo is Purdue Pete's plate, a pwa built on Javascript and vanilla html/css. It is made for Purdue Indy students to track their daily macros and meal intakes from tower dining and get the menu right on their app.

MVP: Live tower dining menu on my phone (in purdue colors) with a "recommended" section based on how the user configures the app.

Device: anything with a working browser

IMPORTANT: CS193 requirements (uploads excetera) are all in the MVP branch (inside docs/)
